# Hueristic

A daily colour-matching game. A hidden colour, three sliders, six tries.

Everyone gets the same colours each day, in the same order. Each try scores hue,
saturation and lightness separately, and tells you which of the three is holding
you up — which turns out to be the useful part.

Built as a single HTML file with no dependencies and no build step. The
leaderboard runs on Supabase; the game works without it.

Play: https://eaustine.github.io/hueristic/
