# Passable

Ten colour pairs a day. For each one, say how far it carries: nowhere, large
text only, or body copy. Those are the three WCAG AA thresholds.

Most pairs sit near a boundary, because that's where the judgement is actually
hard. Your record tracks which way you lean when you're wrong — rating a
failing pair as usable is the mistake that reaches production.

Built as a single HTML file with no dependencies and no build step.

Play: https://eaustine.github.io/passable/
